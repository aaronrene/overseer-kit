# Source quickstart

Start with [Git-only setup](GIT-ONLY-QUICKSTART.md), or the explicit pinned
[Muse authority and mirror guide](FPR-2-AUTHORITY-AND-LANES.md). Use a conventional
venv in the exact kit installation. Repository identity, physical root, selected
lane, authority and runtime are validated on every command.

Use bound `ok next`, `ok status`, `ok check-ok --dry-run`, `ok governance-sync --dry-run`
and `ok app --open`. See [maintained surfaces](FPR-3-PRODUCT-SURFACES.md) for commands,
options and explicit local/remote distinctions. Only `next-write` publishes
canonical `docs/NEXT.md`; HANDOVER and ROADMAP remain paired summaries.

[Local source packaging](SOURCE-DISTRIBUTION.md) is available. This restoration
has not completed combined validation or independent final review and does not
claim a new signed installer, published release or deployment.
