# Pre-reset `.overseer` policy state

These files were tracked under the repository's `.overseer/` directory before the
October 2026 bounded-v1 scope reset. They are preserved as historical evidence and
are not read by the bounded-v1 CLI.

Current checkout-local `.overseer/config.yaml` and `.overseer/bin/` files contain
physical paths and are generated by `ok init` / `ok sync`; they are intentionally
ignored and must not be published.
