# Controlled Muse mirror upgrade

Retain Muse as the selected authority. Inspect bound `ok status` and use
`ok upgrade-regime --help` for the explicit dry-run/apply ceremony. Preserve full
settings and tracked bindings. Approve an isolated owned bare Git mirror target;
use `mirror prepare`, `mirror reconcile`, `mirror verify` and separately authorized
`mirror deliver`. Exact source revision and parent/tree/trailer correspondence
are checked. Legacy `--live-bridge` and live worktree exports are refused.

See [authority and lanes](FPR-2-AUTHORITY-AND-LANES.md) for the complete ceremony
and [source distribution](SOURCE-DISTRIBUTION.md) for matching-config rollback.
No upgrade, remote delivery or consumer installation is implied by reading this
runbook. Keep the completed bounded upgrade/pilot evidence as historical evidence.
