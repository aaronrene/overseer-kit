Install / init (short path)

  1. Download the reviewed v1.0.0-rc.1 installation and rollback guide from GitHub Releases.
  2. From the kit: ./cli/ok -C "$PROJECT_ROOT" init --vcs git --repo-name PROJECT-NAME --lane product --model "MODEL LABEL"
  3. Run the repository-bound launcher with status --json, then next.
  4. Review replacement task text, then use next-write with the current context and prior NEXT digest.

NEXT validates and prints task text from the reviewed prerelease. It does not execute the prompt; use action kind stop when no task remains.
