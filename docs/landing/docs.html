Clone / init (short path)

  1. Clone the kit when you have repo access.
  2. From your project: ./cli/ok -C . init --regime git-only --non-interactive
  3. Open the handover living doc and paste the next prompt into your chat.
  4. Run ./cli/ok governance-sync --dry-run before you end a session.

Primary install for operators: Download Mac console (Apple Silicon).
