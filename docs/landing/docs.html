Start the workflow

  1. Download the reviewed v1.0.0-rc.1 prerelease installation and rollback guide from GitHub Releases.
  2. From the kit: ./cli/ok -C "$PROJECT_ROOT" init --vcs git --repo-name PROJECT-NAME --lane product --model "MODEL LABEL"
  3. Write bounded phases in ROADMAP, freeze the outputs and acceptance evidence, then resolve findings from a separate agent chat or human reviewer before build.
  4. Build the accepted phases, run project-owned checks, and have a separate reviewer compare the result with the freeze before DONE. Update ROADMAP and HANDOVER to match reality, then use next-write to carry the reviewed next task forward.

The reviews are independent actions performed by your chosen agent session or human reviewer. The current reviewed prerelease does not run agents or decide that a plan or build is correct; its public CLI preserves repository-bound continuity between those actions.
