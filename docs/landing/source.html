Prepare local source

This full-product restoration has no new published or signed installer. Combined validation and independent review remain pending.

Use the selected source installation's conventional Python environment and pinned local prerequisites. The full instructions are in docs/SOURCE-DISTRIBUTION.md in that source checkout.

.venv/bin/python tools/ci/source_package.py build --output /absolute/new-source.tar.gz
.venv/bin/python tools/ci/source_package.py verify --archive /absolute/new-source.tar.gz
.venv/bin/python tools/ci/source_package.py unpack --archive /absolute/new-source.tar.gz --destination /absolute/new-installation

The archive carries a hash, size and executable-mode manifest. It excludes live repository bindings, canonical NEXT, stores, virtual environments and secrets. Provision the new installation's own conventional venv before launch. No neighboring installation supplies its runtime.

Desktop resource preparation and local CLI/app operation are distinct from signing, publication and deployment. Keep matching configuration and source backups for explicit quiescent rollback.
