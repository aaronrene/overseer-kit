A — Software engineering

Pain: A new agent session starts in the wrong checkout or follows a handoff written for an older revision.

How the kit helps

  • Baseline: Repository-bound status plus one validated NEXT handoff.
  • Project checks: CI and domain tests remain owned and run by the repository.
  • Operator review: The team reviews the task, work, and merge; Overseer does not approve them.
  • Optional Muse: Select Muse authority and a controlled GitHub mirror when that model fits.

Start with the shipped local workflow: Git-only quickstart

B — Video studio

Pain: A session resumes from stale production notes, and project-specific QC steps are easy to miss.

How the kit helps

  • Baseline: One repository-bound NEXT identifies the reviewed production task.
  • Project checks: The studio may keep its own narration, export, and QC scripts.
  • Human review: A listener can approve the export through the studio’s own process.
  • Optional Muse: Muse authority can retain repository history; the kit does not ship a video workflow.
reference

C — Research paper pipeline

Pain: A research session loses its source context or continues from stale task instructions.

How the kit helps

  • Project checks: A research repository may record source URLs, hashes, quote spans, and regenerated tables.
  • Human review: A researcher can re-fetch sources and compare the draft with project evidence.
  • Optional Muse: Muse authority may preserve repository history when the team chooses it.

Illustrative project workflow — research checks are not shipped in kit core.

illustrative

D — Accounting close

Pain: A close process resumes without a clear repository handoff or current reconciliation task.

How the kit helps

  • Project checks: An accounting repository may define CSV schemas, checksums, and reconciliation thresholds.
  • Human control: Separate preparation and review roles authorize any financial export.
  • Boundary: Overseer does not execute transfers, enforce roles, or provide an accounting domain pack.

Illustrative only — no kit claim of a production accounting workflow.

reference

E — Classroom

Pain: Students resume from copied or stale instructions and may skip the teacher’s project checks.

How the kit helps

  • Baseline: A repository-bound NEXT carries the teacher’s reviewed assignment task.
  • Project checks: The course may require tests and secret scanning before submission.
  • Human review: A teacher or TA reviews the work; Overseer does not grade it.
  • Optional Muse: A course may choose Muse authority; Git-only remains fully supported.

Boundary: This is an example teaching pattern. The kit ships repository context and handoff commands, not a classroom platform.
